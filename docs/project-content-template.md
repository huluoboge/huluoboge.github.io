## Writing Guardrails

- Do not say the project is unfinished if it is completed.
- Do not say benchmark data is missing unless that caveat should appear publicly.
- Do not infer implementation status from absence of materials.
- If a claim, product name, device codename, or repository name is sensitive or adds reader confusion, either omit it or rewrite it as a public technical description.
