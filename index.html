About Me

I am Lead of 3D Reconstruction at Realsee (realsee.com), working across photogrammetry, multi-view geometry, point clouds, meshes, and production reconstruction systems.

My work combines algorithm design, C++/CUDA implementation, validation, and performance optimization, with an emphasis on large real-world scenes and reliable engineering delivery.

我目前就职于如视（realsee.com），负责三维重建方向，长期从事 SfM/MVS、SLAM、点云、网格、纹理与大规模重建系统研发。

Indoor Large-Scale Reconstruction

Indoor large scenes · Station-based scanning · Cloud reconstruction

Built the indoor large-scene reconstruction system behind station-scanned spaces such as Realsee VR house tours, museums, and large venue digitization.

Large-Scene Point Cloud Colorization

Sparse point clouds · Multi-view projection · Semi-global color consistency

Developed a direct colorization pipeline for large sparse point clouds, mapping calibrated multi-view images onto LiDAR geometry while controlling visibility, view selection, and color seams.

  • Built a block-based voxel visibility framework that uses neighboring blocks as occlusion context, Top-K candidate views, point-level projection checks, normal filtering, masks, and rolling-shutter row poses.
  • Designed a distance-driven main-view selection strategy that forms spatially coherent view regions, then applies boundary multi-view consensus and sparse correction-field optimization for semi-global color harmonization.

Tech: C++, OpenVDB, point clouds, ray visibility, multi-view projection, Delaunay graph, conjugate gradient

Handheld LiDAR Point-Cloud Processing

Handheld LiDAR · Point-cloud filtering · Block-parallel refinement

Built a production point-cloud filtering and geometric refinement pipeline for handheld laser scanning, turning raw keyframe clouds into clean global point clouds for downstream reconstruction.

  • Designed a sparse-voxel, block-parallel processing framework with streaming partitioning, neighbor topology, boundary-safe ownership, and global result merging.
  • Implemented time-aware dynamic-object removal, sub-voxel centroiding, robust normal orientation, anisotropic bilateral filtering, MST normal propagation, planar density homogenization, and sparse outlier cleanup.

Tech: C++, OpenVDB, handheld LiDAR, ray traversal, normal estimation, bilateral filtering, Poisson-disk sampling

Station-Based and Handheld LiDAR Calibration

Station-based scanning · Mobile handheld scanning · Camera-LiDAR extrinsics

Designed a calibration workflow for station-based scanning and mobile handheld laser scanners, focusing on practical error sources and the path from diagnosis to validation.

  • Formulated the main calibration problems: coupled sensor and mechanical errors, degraded planar geometry, repeatability risks, and camera-to-LiDAR alignment in production data capture.
  • Used simulation to analyze error distributions, designed optimization and validation schemes, and added a high-precision calibration-field workflow that completes joint camera-LiDAR extrinsic calibration from a single data capture.

Tech: LiDAR calibration, camera-LiDAR extrinsics, error simulation, nonlinear optimization, calibration-field design
