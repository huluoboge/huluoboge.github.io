# STAC 论文解读

> Runze Wang、Yuxuan Song、Youcheng Cai、Ligang Liu，*STAC: Plug-and-Play Spatio-Temporal Aware Cache Compression for Streaming 3D Reconstruction*，CVPR 2026 正式版（正文 10 页）。正文以 [CVF 正式版 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Wang_STAC_Plug-and-Play_Spatio-Temporal_Aware_Cache_Compression_for_Streaming_3D_Reconstruction_CVPR_2026_paper.pdf) 为准；补充材料采用 [arXiv v2 PDF](https://arxiv.org/pdf/2603.20284v2)，并用[官方 arXiv 源码包](https://arxiv.org/src/2603.20284v2)核对在 PDF 分页处截断的内容。[论文页](https://arxiv.org/abs/2603.20284) · [项目页](https://stac-3r.github.io/) · [代码](https://github.com/Rainzor/STAC)

## 摘要

流式三维重建既要利用长时间上下文维持几何一致性，也要控制缓存与推理延迟。StreamVGGT、STream3R 等因果版 VGGT 用 Key、Value（KV）缓存保存过往帧的注意力表示，使新帧不必重新计算全部历史；代价是缓存随视频长度增长。在内存预算有限时，简单丢弃旧 token 会损害重建质量与时间一致性。

STAC 的出发点是，缓存中的 token 并非同等重要：注意力头呈现空间与时间上的稀疏结构，三维位置相近的 token 也存在特征冗余。论文据此提出三部分方法：工作时间缓存保留首帧、近期帧和重要锚点；长期空间缓存把移出时间窗口的 token 按预测三维位置送入体素，并合并相似 KV；分块多帧优化则联合处理已到达的一小组帧，利用块内双向信息提升几何连贯性与 GPU 利用率。

作者在 NRGBD 与 7-Scenes 上报告，STAC 将因果模型约 19.75 GB 的完整缓存压缩到约 2.20–2.57 GB，并把端到端吞吐从约 2.5 FPS 提高到约 10.5 FPS。几何质量与原因果主干接近，但不同数据集、任务和指标上都有升有降；长期空间缓存也会随新区域覆盖而增长，因此这些结果不能被读成任意场景下恒定内存或无精度损失的保证。

## 1 引言

从图像恢复稠密几何和相机运动，是虚拟现实、机器人和自动驾驶等应用的基础。传统 SfM 通过特征提取、匹配、三角化和束调整估计相机，再由 MVS 恢复稠密表面。这些模块化流程成熟，但需要逐步优化，计算量较大，也会受到噪声、遮挡和视角变化的影响。

VGGT 等前馈 Transformer 可以从多视图图像联合预测相机、深度、点图和三维轨迹，减少显式几何优化。可是离线模型通常需要同时访问整组图像；若新帧到来后重新对整段视频推理，会重复计算，而且时延随视频增长。StreamVGGT 与 STream3R 将 VGGT 的全局注意力改成因果注意力：当前帧只读取已经到达的历史状态，并将每层、每头的 K、V 存入缓存。在线计算得以实现，缓存却随历史帧持续增长，长流的内存和延迟因而成为瓶颈。

STAC 将注意力观察归纳为两种互补稀疏性：空间稀疏性表现为某些头随相机运动关注空间邻近区域；时间稀疏性表现为某些 token 长期吸引注意力，例如首帧、稳定地标帧和相机 token。若一律保留相同长度的最近历史，系统会同时丢弃仍有用的地标与保存大量瞬时冗余特征。STAC 希望在不改主干、不额外训练的前提下，分别保留重要的时间线索、压缩空间冗余，并让推理适合 GPU 并行。

## 2 相关工作

### 2.1 基于图像的三维重建

传统 SfM 和 MVS 依赖特征对应与几何优化。学习式离线方法则把几何估计做成前馈预测：DUSt3R 直接回归图像对的点图，MASt3R 在三维空间中建立对应，VGGT 在一个 Transformer 中联合预测相机、深度、点图和轨迹。后续研究将这些模型扩展到数千张图像或公里级序列，但通常仍需整批处理或全局注意力，面对持续到达的视频时会增加计算和显存负担。

在线方法采用潜在状态、空间特征库或三维指针记忆，支持逐帧更新，但往往需要为具体架构设计记忆机制或任务微调。StreamVGGT 与 STream3R 将 VGGT 改造成因果 Transformer，推理过程保留过去的 KV 状态。STAC 直接建立在这类 Causal-VGGT 上，目标不是再设计一个重建主干，而是管理其历史缓存。

### 2.2 KV 缓存压缩

大语言模型中的 KV 压缩常通过淘汰低重要性 token 或合并重复 token 降低长上下文内存。多模态和视频方法也会按查询相关性或显著性压缩信息，但 STAC 指出，三维重建缓存还携带相机运动和三维位置结构。因而，单凭时间顺序或通用 token 重要性做淘汰，可能丢弃再次观察场景时有用的空间证据。STAC 的设计把注意力重要性与解码出的三维位置一起用于缓存管理。

## 3 预备知识

### VGGT 与 Causal-VGGT

VGGT 的图像编码器将每帧 $I_t$ 转成视觉 token $F_t$。离线解码器对所有帧做全局自注意力，产生几何特征 $G_t$，再由预测头输出相机参数 $c_t$、深度图 $D_t$ 和点图 $P_t$：

$$
\{G_t\}_{t=1}^{T}=\mathrm{Decoder}(\mathrm{GlobalSelfAttn}(\{F_t\}_{t=1}^{T})),\qquad
(c_t,D_t,P_t)=\mathrm{HeadDecoder}(G_t).
$$

Causal-VGGT 把全局自注意力换成因果自注意力。第 $\ell$ 层、第 $h$ 个头在时间 $t$ 保存过去各帧的状态 $m_\tau^{\ell,h}=(k_\tau^{\ell,h},v_\tau^{\ell,h})$。当前帧用自己的 Query 查询这些缓存 Key，并以对应 Value 汇聚上下文。这样模型不用重算旧帧，也能把历史信息带入当前预测。

如果每帧产生 $M$ 个 token、解码器有 $L$ 层，保留全历史时缓存条目随帧数 $T$ 大致按 $LMT$ 增长。STAC 处理的对象就是这些跨层 KV 表示；它仍依赖主干输出点图和相机等预测，不替换图像编码器或重建头。

## 4 观察

作者分析 Causal-VGGT 的全局因果注意力图，发现不同头在空间与时间上呈现不同模式。图 2 中，每个 Query 仅保留相关性最高的 1024 个 Key 以便可视化。图 2a 的空间头与相机运动相关，回访区域时会关注空间上相邻的区域；图 2b 的参考头持续读取首帧 token；图 2c 的地标头会反复读取语义稳定的地标帧；图 2d 的相机头关注相机 token，以传递全局上下文。

### 空间稀疏性

某些注意力头随视点变化关注三维空间中相邻区域。作者进一步把 KV token 关联到预测三维坐标，发现空间邻近的 token 常有较高特征相似度；当相机回到已观察区域时，旧 token 可能仍有用。只按时间淘汰会忽略这类空间重复与回访关系。

### 时间稀疏性

另一些头会长期关注少量历史 token。作者将其分为首帧参考、语义稳定地标帧和相机 token 三类。这表明“近期”不等于“重要”：窗口外的某些 token 仍承载坐标参考或全局运动信息，而大量瞬时 token 未必需要长期保存。观察结果促成 STAC 的双重记忆：工作缓存有选择地保留时间重要性，空间缓存则压缩被移出的局部几何证据。

## 5 方法

STAC 不修改 Causal-VGGT 的重建目标，也不重新训练主干。图 3 展示整体流程：当前图像块经 ViT 编码后，由因果解码器读取工作时间缓存和从体素网格检索出的空间缓存，预测相机、深度和点图；解码出的三维坐标用于定位新 token，离开工作缓存的 token 则进入空间缓存。

### 5.1 工作时间 token 缓存

工作时间缓存 $M_t^{temp}$ 由三部分组成：首帧的全局参考 token $M^{refer}$、最近 $s$ 帧的局部窗口 $M_t^{window}$，以及动态维护的锚点 $M_t^{anchor}$：

$$
M_t^{temp}=M^{refer}\cup M_t^{window}\cup M_t^{anchor}.
$$

首帧 token 固定保留，用作之后逐步对齐到统一坐标系的参考；滑动窗口覆盖最近的短期运动与外观连续性；锚点负责记住较长时间内仍被反复使用的历史线索。论文默认窗口长度 $s=4$。

为了更新锚点，STAC 汇总当前帧各 Query 对历史 Key 的注意力。令 $q_j^t$ 为当前帧第 $j$ 个 Query，$k_i^{all}$ 表示本次注意力中可见的 Key，包括时间缓存、空间缓存和当前帧 token；注意力权重为

$$
\alpha_{j,i}^{t}=\mathrm{Softmax}_{i}\!\left(\frac{q_j^t\cdot k_i^{all}}{\sqrt{d_h}}\right),\qquad
s_i^t=\gamma s_i^{t-1}+\sum_{j=1}^{N}\alpha_{j,i}^{t}.
$$

Softmax 沿可见 Key 归一化，$d_h$ 是每头特征维度，$N$ 是当前帧 Query 数。分数以 $\gamma=0.9$ 衰减旧累计量，再加上本帧所有 Query 对 token $i$ 的注意力总和。新生成的 token 以本帧累加注意力初始化。因而分数表示模型在一段时间内使用该 token 的程度，是保留优先级，不是几何精度置信度。

滑动窗口前移时，STAC 在已有锚点与即将离开窗口的 token 中，按 $s_i^t$ 选 Top-$K$ 作为下一时刻的锚点集合。近期 token 要么继续留在滑窗，要么凭累计重要性进入锚点；其余淘汰 token 交给空间缓存。这样，时间缓存控制近邻上下文，同时保留少数跨较长时间仍重要的引用。

### 5.2 长期空间 token 缓存

仅有时间窗口和锚点仍会丢掉早期区域的大量空间证据。STAC 因此把被淘汰 token 按三维位置分配到固定分辨率体素。每个体素 $u$ 维护两个集合：长期代表集合 $G_u$ 和近期淘汰缓冲区 $E_u$。前者存放已合并的代表 token，后者暂存尚不适合直接合并的差异 token。

#### 一对一合并

到达体素 $u$ 的淘汰 token 记作 $m_e=(k_e,v_e)$。若 $G_u$ 非空，先在其中寻找与 $m_e$ 的 Key 余弦相似度最高的代表 $\hat m_p$。只有当相似度超过阈值 $\lambda$ 时才合并；Value 也随 token 一起更新。代表及新 token 的权重分别为历史累计权重 $Z(\hat m_p)$ 和 $\omega=\exp(\mathrm{cos}_k(m_e,\hat m_p))$，更新为

$$
\hat m_p\leftarrow\frac{Z(\hat m_p)\hat m_p+\omega m_e}{Z(\hat m_p)+\omega},\qquad
Z(\hat m_p)\leftarrow Z(\hat m_p)+\omega.
$$

这不是单纯平均：Key 越相似，当前 token 在代表更新中的权重越大；累计权重记录代表吸收过的信息量。如果相似度不够，或长期集合尚为空，$m_e$ 先进入 $E_u$，以免过早把可能不同的证据混在一起。

#### 缓冲聚合与容量重整

当 $E_u$ 积累到容量（默认每体素最多 8 个暂存 token）时，STAC 围绕其中注意力分数最高的 token 选一个 pivot，按 Key 相似度加权，把缓冲 token 聚成新代表并放入 $G_u$。默认每个体素最多保留 4 个长期代表。若 $G_u$ 已满，先找累计权重最小的代表，再将它合并到 $G_u$ 中最相似的其他代表，腾出位置给新聚合代表。补充材料将该流程写成在线算法，并推导在无法访问已丢弃原 token 的情况下如何近似执行代表间重合并。

由此，$G_u$ 表示多次观察后形成的稳定摘要，$E_u$ 则暂存不够相似、还未归并的证据。相似度阈值 $\lambda$ 控制一对一合并的激进程度；固定容量保证单个体素内条目不会无限累积，但活跃体素数量仍可能随场景范围增加。

#### 空间检索与计数偏置

当前帧的解码头输出点图 $P_t$ 后，STAC 将像素三维点量化到体素，得到可见体素集合 $V_t$，再按体素中心的 kNN 搜索扩展成邻域 $\mathrm{Nbr}(V_t)$。空间缓存 $M_t^{spat}$ 由这些邻域中所有 $G_u$ 和 $E_u$ 的 token 组成。仅检索当前几何附近的记忆，避免每帧重新读完整空间缓存。

合并会让多个历史 token 变成一个代表。若仍把每个代表视作一个普通 token，其注意力影响可能因条目减少而变小。STAC 为合并代表保存计数 $n$，在注意力 logit 中加入 $\log n$：

$$
\frac{q\cdot k}{\sqrt{d_h}}+\log n.
$$

这项偏置补偿代表吸收的 token 数量，使聚合前的历史权重不会仅因压缩而消失。注意力稀疏观察与空间缓存相似度分析支持这一设计，但其合理性仍依赖预测坐标和 Key 相似度能反映“可合并”的证据。

### 5.3 分块多帧优化

逐帧处理计算粒度小，GPU 利用率有限；若任意读取未来帧，又会破坏流式因果条件。STAC 将已经到达的连续帧组成小块，并在块内做双向注意力，块边界仍只允许访问当前时刻之前已经到达的帧。论文称之为 chunk-causal：块中不包含任何未来尚未到达的图像，块内帧则可以互相提供信息。默认块大小为 4。

分块允许有限的块内信息交换，论文观察到局部几何更一致；同时，块级运行可以摊薄 kernel 启动和数据传输开销。代价是系统要等当前块收齐才联合处理，因此在线输出会有最多一个块的输入等待，不能等同于零等待的逐帧响应。作者还将体素坐标转成保持局部性的 Morton 编码，并在前向后批量处理多层 token 选择、合并和检索，以降低缓存管理开销。

## 6 实验

### 6.1 实现细节与比较对象

论文将 STAC 接入 Causal-VGGT 风格的 StreamVGGT 与 STream3R。默认参数为注意力分数衰减 $\gamma=0.9$、体素边长 $r=0.05$、Key 余弦阈值 $\lambda=0.8$，每体素至多 $|G|=4$ 个合并代表和 $|E|=8$ 个暂存 token，检索范围为两倍体素半径。KV 以 float16 存储。除首帧缓存外，其余预算按帧 token 数的 8 倍设置：50% 给近期窗口（$s=4$）、25% 给锚点、25% 给取回的合并 token；若取回的合并 token 不足，则用淘汰缓冲 token 补足。分块大小为 4。实验运行在单张 40 GB A100 上，并使用自定义 CUDA kernel 同时计算注意力输出与重要性分数。

基线包括固定窗口的 STream3R-W 与 StreamVGGT-W、在线模型 Spann3R、CUT3R、Point3R，以及基于图像对和全局对齐的 DUSt3R、MASt3R、MonST3R。滑窗比较中保留首帧，并扩大窗口来匹配内存预算。论文也比较完整缓存的 StreamVGGT、STream3R；不同任务下的吞吐和精度仍须结合所用主干、测量范围理解。

### 6.2 评测结果

#### 三维点图重建

主文在 NRGBD 与 7-Scenes 上评测点云重建，输入为 $518\times392$，每隔 5 帧采样关键帧，每个视频片段约 200–300 帧。报告 Accuracy（Acc）、Completion（Comp）、Normal Consistency（NC）：Acc 与 Comp 越低越好，NC 越高越好。内存列对 STAC 报告总占用，其中括号是运行时内存；FPS 是从图像输入到最终三维输出的端到端吞吐。

![原论文表 1：NRGBD 与 7-Scenes 的点图质量、内存和速度](figures/table1-reconstruction.jpg)

*原论文表 1。W8 为滑窗长度 8；W22、W26 用于匹配总内存预算。STAC 的内存主值包含空间 token 存储，括号内为运行时 KV 占用。*

STream3R 在 NRGBD 上使用完整缓存时为 19.75 GB、2.52 FPS；STream3R-STAC 为 2.20 GB（运行时 0.86 GB）、10.53 FPS。StreamVGGT-STAC 为 2.57 GB（运行时 0.86 GB）、10.49 FPS。按总占用比较，缓存缩小约 8–9 倍，吞吐约提高 4.2 倍。质量则需按数据集和指标分别看：STream3R 的 NRGBD 平均 Acc 从 0.053 变为 0.065（误差增大），StreamVGGT 从 0.134 变为 0.126（误差减小）；7-Scenes 上也并非每项都同向变化。

在相近内存预算下，STAC 总体上优于 W8 滑窗基线；它也与更大窗口的 W22、W26 作比较。论文将 STAC 描述为更好地平衡重建质量、内存和计算开销。这个比较的意义是同预算下各缓存策略的差异，不代表 STAC 在所有数据集和指标上都超过完整历史主干。

## 7 结论

STAC 从 Causal-VGGT 缓存中的结构化时空稀疏性出发，把历史拆成时间工作集与空间记忆：首帧、近期帧和高注意力锚点保留连续上下文；离开窗口的 token 按三维位置进入体素，使用相似度加权合并、缓冲聚合与容量重整；检索时只读取当前点图附近的空间记忆，并用计数偏置补偿合并数量。分块多帧优化则在不读取尚未到达帧的前提下，换取块内上下文和 GPU 并行效率。

论文在室内重建评测中显示显著的内存与速度收益，同时报告了精度波动。它的实现边界也很清楚：长期空间缓存取决于活跃体素，环境覆盖范围增大时体素数会继续增加；快速运动会导致同一空间位置的特征难以合并；分块引入等待时间；缓存预算与体素、阈值等设置共同决定质量。STAC 是可插入现有因果几何主干的缓存管理方法，不是对任意环境都提供固定内存上界的完整 SLAM 系统。

### B 在线 token 合并算法

补充材料 B 将体素内更新写成在线算法。新 token 到来后先尝试与长期代表集合做最近 Key 匹配；超过 $\lambda$ 就按累计权重加权合并，否则进入暂存集合。当暂存集合满时，以其中注意力分数最高的 token 为 pivot 聚合成新代表。如果长期代表集合已满，就将累计权重最低的代表合并到它的最近邻，再腾出一个槽位。论文还推导了重合并的近似公式：由于旧 token 已被压缩且不可恢复，不能重新对原始样本精确聚合，只能使用代表向量与累计权重近似更新。
